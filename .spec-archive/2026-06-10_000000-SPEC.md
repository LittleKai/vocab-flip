## Parallel Execution Recommendation
- **Safe To Run In Parallel**: Phase 2 (AI Card Studio / API) có thể chạy song song với Phase 3 (Sync) vì AI API Gateway chủ yếu làm ở phía Backend, ít đụng độ SQLite layer.
- **Should Not Run In Parallel**: Phase 1 phải chạy xong trước vì nó cấu trúc lại `SchedulerEngine` và `Flashcard` data model, ảnh hưởng mọi nơi.
