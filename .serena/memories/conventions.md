# VocabFlip conventions
- Keep changes surgical; do not refactor unrelated code.
- Keep Provider architecture; reuse existing repository/DAO/service patterns.
- Any new UI copy must be localized in both English and Vietnamese.
- Follow existing file organization under `lib/core`, `lib/data`, `lib/presentation`, `lib/l10n`.
- On web, prefer safe remote image rendering over local file download for cross-origin assets.
- Update `.claude/PROJECT_SUMMARY.md` when current features or known issues change.
