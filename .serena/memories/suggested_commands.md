# VocabFlip suggested commands
- `flutter run` - launch app.
- `flutter analyze` - full project analysis.
- `flutter test` - run tests.
- `dart format <files>` - format changed Dart files.
- Windows PowerShell context: use `Get-Content -LiteralPath`, `Get-ChildItem -Force -LiteralPath`, `Get-Date`.
- Prefer focused `flutter analyze <paths>` for touched files when validating a bugfix.
