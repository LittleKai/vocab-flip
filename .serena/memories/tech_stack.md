# VocabFlip tech stack
- Flutter 3.x / Dart.
- UI: Material 3.
- State management: Provider.
- Local data: SQLite/sqflite-style DAOs and repositories.
- Remote: Dio-based REST client, Mongo-backed public library services, sync notifications, ratings.
- Image handling: local storage on mobile/desktop; web should keep remote URLs for cross-origin-safe rendering.
- Localization: Flutter l10n with English + Vietnamese ARB files.
